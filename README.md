CadranEditor is an open-source watch face editor for the Ksix Compass smartwatch.

## Supported Devices
| Device | Resolution |
|---------------------|------|
| IDW18 | 240x240 |
| IDW23 | 240x240 |
| IDS02 | 240x240 |

More devices with different screen resolutions will be added in future releases.

## Important notes
CadranEditor was originally made by sptech38. However, he abandoned the project, so updates will be provided and maintained in this repository by uysx.
